<section class="content-section" aria-labelledby="research-context">
  <h2 id="research-context">Improving compute and memory together</h2>
  <p>My doctoral research at IIT Gandhinagar examined how circuit and architectural choices affect the energy, performance, and robustness of domain-specific hardware, with AI workloads as a major focus.</p>
  <p>On the compute side, I explored approximate arithmetic and number representations that reduce the cost of operations and the amount of data stored. On the memory side, I developed in-memory computing circuits and studied architectures that reduce data movement. Hardware–software codesign and modelling tools helped connect those choices with application-level behaviour.</p>

<section class="content-section" id="compute" aria-labelledby="compute-heading">
  <h2 id="compute-heading">Compute and number representation</h2>
  <p>Arithmetic complexity and numerical precision influence the cost of computation, storage, and data transfer. These projects explore approximation and workload-appropriate representations while evaluating output quality.</p>
  <div class="project-grid"><article class="project-card"><span class="eyebrow">ASP-DAC 2023 · Best Paper Candidate</span><h3>Approximate posit multipliers for DNN accelerators</h3><p>Co-developed a hardware–software codesign approach using approximate posit arithmetic in DNN accelerators. The work links number representation and multiplier design with compute efficiency, buffer requirements, and data-transfer cost, evaluated alongside neural-network accuracy.</p><a class="text-link" href="{{ '/publications/#posit' | relative_url }}">View publication</a></article>
<article class="project-card"><span class="eyebrow">ISCAS 2020</span><h3>Approximate adders and floating-point dividers</h3><p>Worked on FPAD, a multistage approximation methodology for floating-point division, and SEDAAF, an FPGA implementation of exact and approximate adders for approximate processors. These projects explore how arithmetic design trades numerical accuracy for lower hardware cost.</p><div class="actions"><a class="text-link" href="{{ '/publications/#fpad' | relative_url }}">FPAD</a><a class="text-link" href="{{ '/publications/#sedaaf' | relative_url }}">SEDAAF</a></div></article>
<article class="project-card"><h3>Developed VosTrOF: A Unified Tool for Design Space Exploration of Approximate Arithmetic Circuits</h3><ul><li>Designed VosTrOF, a tool that unifies four approximation strategies (Truncation, Overclocking, Voltage Overscaling, and Functional Approximation) for adders, multipliers, and dividers, enabling holistic analysis and design space exploration</li><li>Utilized VosTrOF for eight separate image processing applications, demonstrating optimized designs</li></ul></article>
<article class="project-card"><h3>Compression and Quantization of Convolutional Neural Networks</h3><ul><li>Surveyed compression and quantization techniques for Neural Networks to reduce memory and compute requirements during inference</li><li>Implemented logarithmic quantization in Python for various neural networks and analyzed the effects</li></ul></article></div>
</section>
<section class="content-section" id="memory" aria-labelledby="memory-heading">
  <h2 id="memory-heading">Memory and in-memory computing</h2>
  <p>Memory research addresses both the cost of accessing data and the opportunity to compute within the array. My work spans compute circuits, memory peripherals, architecture modelling, and compiler development.</p>
  <div class="project-grid"><article class="project-card"><h3>Digital In Memory Computing (IMC) in 6T SRAM</h3><ul><li>Conducted Compute Disturb Analysis and Proposed Mitigation techniques for SRAM 6T-based Digital IMC</li><li>Designed IMC Architecture including Decoder and Peripherals</li><li>Developed Compute Circuits for bit-serial addition, multiplication, and MAC operation</li><li>Designed a Compute-enabled Sense Amplifier robust to process variation</li></ul></article>
<article class="project-card"><h3>Analog In Memory Computing in 6T SRAM</h3><ul><li>Proposed a column-major analog IMC for multi-bit multiplication with minimal changes to peripheral circuits</li><li>Developed a compute-disturb free IMC architecture with high dynamic range and resilience to process variations</li><li>Identified wordline degradation as a major source of non-linearity in analog and digital IMC</li><li>Implemented four wordline shaping techniques to improve access time and reduce inconsistency in bitline discharge</li><li>Proposed a novel process variation tracking method for analog IMC to compensate for process variation</li></ul></article>
<article class="project-card"><h3>Simulator Design for Digital IMC</h3><ul><li>Designed i-CACTI simulator for application-level analysis of Digital IMC</li><li>Built FastMem simulator for accurate and fast SRAM modeling integrated with Digital IMC Compute Logic using Bit Serial and Bit Parallel paradigms of computation</li><li>Built NeuroCACTI-IMC to calculate performance metrics for in-memory computations in SRAM-based memory sub-system, achieving 8X improvement in EDP for BPA and BSA by modifying memory array structure.</li></ul></article>
<article class="project-card"><h3>Developed SRAM Memory Compiler</h3><ul><li>Analyzed the performance metrics of SRAM arrays generated by OpenRAM compiler in NCSU45nm, ranging from 8B to 4KB</li><li>Ported OpenRAM memory compiler to UMC65nm and UMC28nm at both schematic and layout levels, performing a detailed analysis across multiple technologies</li><li>Optimized the performance of the complete Memory subsystem by properly sizing transistors in custom library cells and implementing circuit-level changes</li></ul></article>
<article class="project-card"><h3>Heterogeneous SRAM Cell Sizing for Low-Power Image Processing Applications</h3><ul><li>Designed an 8x8 array of 6T SRAM cells with 8 cells in a row of heterogeneous/different sizes</li><li>Simulated and performed read/write operations with the help of peripheral circuitry in Cadence Virtuoso using UMC 65nm technology</li><li>Developed a 1000X faster algorithm than the proposed one to find optimum sizes for heterogeneous SRAM cells using the Dynamic Programming approach.</li></ul></article></div>
</section>
